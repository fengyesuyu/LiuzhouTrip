# 柳州 48 小时 · 16 家店打卡表

周末两天的柳州吃店路线：16 个点位、按营业时段拆成两天、手机端单页、地图实时定位。

- 页面：`index.html`
- 数据：`assets/data.js`（16 条店铺的唯一来源，改店名/时间只改这里）
- 地图：`assets/config.js`（高德 Web 服务 Key）+ 本地 Leaflet，无 CDN
- 坐标：**不预存**，打开页面时按店名实时查询，查不到就显示「未定位」

## 数据来源

抖音「一支凯子」第 48 集《极限48小时二刷柳州，连着两天吃了18家店》的口播与逐帧字幕；
地址和营业时段来自高德 POI 实时查询及本地攻略交叉核对。
口播编号到 18 站但只点名 14 家（第 4、11 站剪辑时未保留），页面里 2 家标为「视频未点名」的推断点。

## 本地预览

```bash
cd liuzhou
python -m http.server 8099
# 打开 http://127.0.0.1:8099/
```

> 直接双击 `index.html`（file://）会被浏览器拦截实时定位请求，页面里会给出提示。
